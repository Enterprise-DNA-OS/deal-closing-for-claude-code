# Rules and evidence

This is a corporate transaction work record for the responsible legal team. It does not make legal decisions, verify an electronic signature, execute an agreement, handle client money or submit a filing. Applicability, retention duties, execution formalities and contractual deadlines are determined by the responsible lawyer. There is no claim of regulatory certification.

Sources checked 17 November 2026. The reminders apply as a review checklist to all demonstration deals; jurisdiction and entity coverage must be checked before use.

| Rule | What the code checks | Authority or policy |
|---|---|---|
| NZ-IPP1 / AU-APP3 | A recorded purpose exists for holding personal information | [NZ purpose of collection](https://www.privacy.org.nz/privacy-principles/1/) and [Australian Privacy Principles](https://www.oaic.gov.au/privacy/australian-privacy-principles/read-the-australian-privacy-principles). A nonempty field alone does not establish necessity. |
| NZ-IPP5 / AU-APP11 | Access review date is present and has not passed | [NZ storage and security](https://www.privacy.org.nz/privacy-principles/5/) and [OAIC APP 11](https://www.oaic.gov.au/privacy/australian-privacy-principles/australian-privacy-principles-guidelines/chapter-11-app-11-security-of-personal-information). A date is a reminder, not proof that access is secure. |
| NZ-IPP9 / AU-APP11 | Retention review date is present and has not passed | [NZ retention](https://www.privacy.org.nz/privacy-principles/9/) and OAIC APP 11 above. Review purpose and overriding retention obligations. The tool never deletes on a timer. |
| FIRM-EVIDENCE | Completion references the current revision, an actor and evidence | Demonstration firm policy, not a statutory deadline or prescribed legal test. Changes reopen downstream conditions. |
| FIRM-SIGNATURE | Every required signer has recorded evidence against the current document version | Demonstration firm policy. The responsible lawyer determines the required signers and checks authority, execution, witnessing and delivery. No assumption that an entry makes a signature valid. |

`compliance` lists findings. `review-privacy` records the reviewer, evidence and next dates. Dates are selected by the firm, never described as statutory periods. A clear report means these record checks passed, not that the transaction complies with every law.

The database is for trusted operators. RLS has no public access policies. Configure the database role, disk encryption, backups, retention and separate matter access before shared use. Actor names are operator supplied, not authenticated identities. Database administrators can alter history; the log is not tamper-proof. Keep original signed documents in the firm's controlled storage and reconcile their hashes.
