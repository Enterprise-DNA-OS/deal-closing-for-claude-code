# Why this has no application front end

The daily work is a closing list, an evidence register and a decision about what is ready. A coding agent runs one CLI over your database. Read-only HTML gives the team a closing checklist, signature matrix and closing book index in its own brand.

Legatics offers shared online lists, document viewing, granular permissions, signing connections and binders. Those are useful features. This base has no collaborative browser editing, mobile or offline application, drag and drop, document signing service, client portal or merged PDF binder. It stores file references and hashes rather than hosting documents. It does not replace a lawyer's review or an electronic signing provider. A screen and those integrations can be scoped into the version Enterprise DNA builds for a firm.

Generated HTML is a snapshot. Run it again for current data, keep it private, and use the CLI when acting. The database remains readable by Claude Code, Codex, OpenCode, Cursor and other coding agents through the same instructions.
