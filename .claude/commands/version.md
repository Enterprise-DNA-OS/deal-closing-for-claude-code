Read the local file and use its durable controlled-storage reference. The command hashes bytes and stores metadata; it does not copy the file. It reopens the item and dependent work. Earlier signature evidence remains historical.

Example syntax (replace demonstration values):

```bash
npm run closing -- version --deal=NEW-01 --ref=DOC-01 --file=imports/agreement.pdf --reference="controlled/agreement-v2.pdf" --actor="Operator" --json
```
