# Customise the closing desk

Read CLAUDE.md and the current schema. Agree the requested field, wording or rule with the operator from their ask. Add a new numbered migration rather than changing an applied migration. Update CLI validation, imports, relevant reports, paperwork and these command recipes. Apply the migration, run npm test and the affected report, and show a before/after example from demo data.

Keep evidence tied to the revision. Never weaken closing gates without an explicit operator request and a clear explanation of the effect. Never infer a legal rule or fabricate an approval. A new field does not need a new application front end.
