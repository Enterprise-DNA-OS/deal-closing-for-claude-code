# Weekly closing review

Run `npm run closing -- closing-readiness --json`, `npm run closing -- attention --json` and `npm run closing -- signatures-due --json`. Then run post-closing for the obligations that survive completion. The weekly-review CLI combines the same four reports.

Write the Monday review: closing dates at risk; each blocker with code, owner and deadline; missing current signatures; unowned and overdue post-closing work. Cite the records. Do not call a transaction closed without a human instruction and a recorded closing decision. Prepare draft-chaser where requested; nothing sends.
